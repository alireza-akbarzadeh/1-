## 🗓️ Weekly Breakdown

### Week 1: Audit & Foundation
- **Core:** JavaScript Deep Dive  
  _Scope, closures, this, call/apply/bind, prototype chain, event loop_  
  **Resource:** [You Don’t Know JS](https://github.com/getify/You-Dont-Know-JS) / [Frontend Masters](https://frontendmasters.com/)
- **Project:** Start dashboard app (Next.js + Tailwind + Zustand)
- **Reflect:** List your strengths & weaknesses
- **Bonus:** Setup dotfiles, ESLint/Prettier config

---

### Week 2: TypeScript Mastery
- **Core:** Deep dive into utility types, generics  
  **Resource:** [Type Challenges](https://github.com/type-challenges/type-challenges)
- **Project:** Migrate app to TypeScript
- **Reflect:** Note common type errors
- **Bonus:** Create a custom utility type

# 🌟 12-Week Frontend Mastery Plan

**Goal:** Become a world-class frontend engineer with strong product-thinking, architectural depth, and career-proof skills that make you 10x more valuable than AI-assisted coders.

---

## 📅 Structure
- **Duration:** 12 weeks
- **Time Commitment:** ~10 hrs/week
- **Weekly Focus:**
  - 1 Core Topic
  - 1 Side Project Task
  - 1 Review/Reflect Task
  - 1 Optional Advanced/Bonus Topic

---

## Week 1: Audit & Foundation
- Core: JavaScript Deep Dive
  Scope, closures, this, call/apply/bind, prototype chain, event loop.
  Resource: You Don’t Know JS or Frontend Masters
- Side Project: Start a dashboard app (Next.js + Tailwind + Zustand)
- Reflect: List your strengths/weaknesses
- Bonus: Setup dotfiles, eslint/prettier config

## Week 2: TypeScript Mastery
- Core: Deep dive into utility types, generics
  Resource: Type Challenges
- Side Project: Migrate app to TypeScript
- Reflect: Note common type errors
- Bonus: Create a custom utility type

## Week 3: React Internals & Advanced Hooks
- Core: React render flow, fiber, reconciliation
- Side Project: Build custom hooks: useMediaQuery, useDebounce
- Reflect: Explore React internals
- Bonus: Read React source code for useEffect

## Week 4: Component Architecture
- Core: Scalable design patterns, atomic design
- Side Project: Card list to detail view
- Reflect: Component reusability
- Bonus: Explore UI libraries like Radix, ShadCN

## Week 5: State Management at Scale
- Core: Zustand, Redux Toolkit, React Query, Context
- Side Project: Settings panel with persisted state
- Reflect: State management decisions
- Bonus: Learn React Server Components

## Week 6: Testing & Reliability
- Core: Unit, integration, E2E testing
- Side Project: Add test coverage for auth flow
- Reflect: Testable design principles
- Bonus: Setup CI with GitHub Actions

## Week 7: Performance Optimization
- Core: Lighthouse, code splitting, memoization
- Side Project: Image optimization, measure TTI/CLS
- Reflect: Use DevTools to find bottlenecks
- Bonus: Setup Sentry + monitoring

## Week 8: CSS at Scale & Design Systems
- Core: Tailwind CSS or styled-components
- Side Project: Build reusable UI components
- Reflect: Ensure design consistency
- Bonus: Setup Storybook

## Week 9: Accessibility, i18n, UX Polish
- Core: Screen reader, keyboard nav, a11y
- Side Project: Add i18n + accessibility
- Reflect: Run contrast/focus audits
- Bonus: Use axe-core or Lighthouse

## Week 10: Backend Basics
- Core: Node.js, REST, GraphQL, auth flows
- Side Project: Express or tRPC backend with auth
- Reflect: API design patterns
- Bonus: Integrate with Prisma or Drizzle

## Week 11: Developer Experience & Automation
- Core: CI/CD, Prettier, ESLint, Vite/Next config
- Side Project: Automate formatting, deploy to Vercel
- Reflect: Dev workflow improvements
- Bonus: Try code generation from OpenAPI

## Week 12: Personal Branding & Proof of Work
- Core: Update GitHub, LinkedIn portfolio
- Side Project: Deploy dashboard + landing page
- Reflect: Showcase work for instant impact
- Bonus: Write a blog post or record a video
